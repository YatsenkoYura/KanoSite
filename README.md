### Скачивание и подготовка
```bash
git clone https://github.com/YatsenkoYura/KanoSite.git
cd KanoSite
7z x data/db.7z -odata/
cp .env.example .env
```
### Настройка

Подредактируйте .env файл, вставьте свой ключ для openrouter, введи свои данные для metabase. Придумайте сложный пароль для базы данныхю Заполните поля.

### Первый запуск

Если все настреоно правильно, можно запускать. Первый запуск требует миграции базы данных, так что первый запуск слегка отличается от остальных.

```bash
docker compose --profile migrate up --build
```
Если все получилось, можно перейти к проверке.

### Как подключится

На вашей сети, в 5000 порте будет доступен сайт. а на 3000 metabase

### Как запустить повторно, когда уже собрано?
Вам стоит вернутся в папку проекта и прописать
```bash
docker-compose up --build -d
```
И проект будет запущен в фоне.

### Настройка metabase

Это отдельный пункт. База данных хостится внутри докер, так что адресс будет `db`, порт `5432`, база данных `appdb`. Логин и пароль которые в `.env`

#### После этого база данных подключится к биосистеме и будет доступна для анализа.
